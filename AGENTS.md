# Guía para agentes

- Este proyecto es un prototipo de LavaTrack para pruebas con usuarios: un inicio de sesión con roles y cuatro paneles operativos (recepción, control de prendas, entregas que une delivery y despacho en tienda, e historial de entregas) que funcionan solo en el navegador con datos ficticios en memoria. No debe conectarse a servicios externos ni guardar cambios.
- Todo el texto de interfaz, nombres de variables, funciones, clases CSS e IDs va en español. Las clases CSS usan `snake_case`.
- Cualquier flujo con pasos se presenta en una ventana flotante con el componente `AsistentePasos`.
- Las listas se generan a partir de arreglos de datos; no repitas marcado estático.
- No uses emojis en la interfaz: usa iconos de `lucide-react`.
